📷 ESP32-CAM Setup (Ojo)

El ESP32-CAM captura video QVGA (320×240) y lo envía como JPEG por WebSocket al servidor.

📋 Requisitos

HardwareESP32-CAM AI-Thinker
AdaptadorConvertidor USB-TTL 3.3V (FTDI/CH340)
PinoutGPIO0 a GND (para flash), 5V, GND, TX, RX, 3V3(UART)

🛠️ Arduino IDE

# En Arduino IDE → Preferences → "Additional Boards Manager URLs":
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

# Luego: Tools → Board → Boards Manager → "esp32 by Espressif" → Install

⚙️ Credenciales WiFi

cp shared/secrets.h.example devices/esp32_cam/secrets.h
# Editar secrets.h:
#define WIFI_SSID   "TU_RED"
#define WIFI_PASSWORD "TU_PASSWORD"

🔌 Configuración

Tools → Board: "ESP32 Wrover Module"
       → Flash Size: "4MB (FS: 1MB, OPI: off)"
       → Upload Speed: 921600
       → Port: (tu adaptador USB-TTL)

📤 Subir firmware

# Conectar GPIO0 a GND, pulsar Reset, subir
# La primera compilación descargará la librería esp_camera automáticamente

💡 Troubleshooting

"Camera fail 0x20002": Aumenta el delay de energía o usa fuente externa 5V.
"WiFi no conecta": Verifica SSID/password en secrets.h. El ESP32-CAM no soporta 5GHz.
Monitor Serie: 115200 baudios. Debes ver "Camara OK", "WiFi OK", "WS conectado".
