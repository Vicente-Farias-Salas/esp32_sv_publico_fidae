🏋️ Arduino Uno Setup (Músculo)

Recibe coordenadas por I2C del ESP32-WROOM y controla two servos Pan/Tilt (non-blocking, sin delay).

📋 Requisitos

HardwareArduino Uno (o compatible)
Servos2× SG90 (Pan: pin 9, Tilt: pin 10)
I2CSDA → A4, SCL → A5
Fuente5V externa recomendada (los servos pueden resetear el Arduino)

🔌 Wiring

Servo Pan  → Arduino pin 9  (PWM)
Servo Tilt → Arduino pin 10 (PWM)
SDA       → A4
SCL       → A5
I2C addr  → 0x08 (definido en shared/config.h)

Fuente externa 5V:
  Servo rojo    → 5V fuente
  Servo negro   → GND fuente + GND Arduino (común)
  Servo blanco/amarillo → pin 9 o 10

📤 Subir firmware

Arduino IDE → Board: "Arduino Uno"
→ Abrir devices/arduino_musculo/m_sculo_arduino_uno.cpp
→ Seleccionar puerto y subir

# O requiere shared/config.h en el mismo directorio

💡 Cómo funciona

El Arduino es I2C Slave (addr 0x08):

  1. Recibe 2 bytes: targetX, targetY
  2. ISR receiveEvent() los valida (bounds [0-180])
  3. loop() usa millis() — NO delay() — para mover 1° cada 15ms
  4. Los servos se mueven mientras el Arduino sigue escuchando I2C

⚠️ Troubleshooting

Servos no se mueven: Verifica I2C con pull-ups 4.7kΩ. Usa config.h en el mismo directorio.
Arduino se reinicia: Los servos consumen corriente. Usa fuente externa 5V separada.
Serial a 9600 baudios. Mensaje: "Musculo OK" en boot.
