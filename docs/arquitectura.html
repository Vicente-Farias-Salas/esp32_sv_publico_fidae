Sistema FIDAE — Documentación de Arquitectura

Sistema distribuido de visión, tracking y control de servos

1. Introducción

El Sistema FIDAE es un proyecto de ingeniería que integra visión por computadora, comunicación en tiempo real y control de hardware para rastrear objetos y apuntar una cámara mediante servos. La arquitectura distribuida separa el procesamiento intensivo (YOLO en Colab con GPU) del hardware de captura (ESP32-CAM) y el control físico (Arduino Uno).

4. Flujo de Datos

  1. Captura: ESP32-CAM captura frame QVGA (320×240) a 10 FPS, lo envía como JPEG binario por WebSocket (?type=camera).
  2. Relay: api/socket.js en Vercel reenvía el frame al cliente Colab (?type=colab).
  3. Procesamiento: Colab ejecuta YOLOv8n, detecta objetos/personas, calcula errores de centro, aplica pursuit smoothing, y envía JSON {"pan":X, "tilt":Y} de vuelta al relay.
  4. Control: Relay reenvía el JSON al ESP32-WROOM (?type=translator), que lo valida, clampa a [0,180], y lo envía por I2C al Arduino.
  5. Actuación: Arduino Uno recibe I2C de forma atómica (uint8_t), ejecuta movimiento non-blocking con millis() + aceleración, y controla dos servos.
  6. Visualización: Colab también envía el frame procesado (con overlays HUD) al relay, que lo reenvía al dashboard web.

6. Configuración

WiFi Credentials

cp shared/secrets.h.example devices/esp32_cam/secrets.h
cp shared/secrets.h.example devices/esp32_wroom/secrets.h
# Edit secrets.h con tus credenciales WiFi

URL del Servidor WebSocket

Edita shared/config.h line 6:

#define WS_HOST  "TU-PROYECTO.vercel.app"

Deploy Vercel

npm install -g vercel
vercel login
vercel --prod
