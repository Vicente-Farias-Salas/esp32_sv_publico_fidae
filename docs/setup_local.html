🏠 Setup — Local (sin Vercel ni Render)

Ejecuta todo el sistema en tu red local. El WebSocket server corre en tu PC y los ESP32 se conectan por IP local.

📁 Estructura local/

local/
├── server.js        # WebSocket relay + HTTP server (Node.js)
├── dashboard.html   # Dashboard web
├── cerebro_local.py # YOLO brain (Python, CPU/GPU local)
├── esp32_config.h   # Config con IP local
├── package.json     # npm dependencies (ws)
└── README.md        # Instrucciones rápidas

🚀 1. Iniciar el servidor

cd local/
npm install    # una vez (instala 'ws')
node server.js # inicia en http://TU_IP_LOCAL:8080

# El server escucha en 0.0.0.0:8080 (accesible desde la red)

📡 2. Configurar ESP32

# En local/esp32_config.h:
#define WS_HOST  "192.168.1.100"  # IP de tu PC en la red local
#define WS_PORT  8080
#define WS_PATH  "/socket"

# Cargar este config.h en cada ESP32:
cp local/esp32_config.h devices/esp32_cam/config.h
cp local/esp32_config.h devices/esp32_wroom/config.h

🖥️ 3. Dashboard

Abre en tu navegador:

http://TU_IP_LOCAL:8080/

🧠 4. Cerebro (YOLO local)

# Opción A: Python con GPU local (si tienes CUDA)
pip install ultralytics opencv-python websockets numpy
python local/cerebro_local.py

# Opción B: Colab conectando a tu IP local (requiere ngrok)
# En Colab: !pip install pyngrok
#           !ngrok http 8080
#           Cambiar WS_URL al forwarding URL de ngrok

                                                       │

                                                       ├─→ server.js (Node.js)
Navegador ────http://192.168.1.100:8080/────────────────────┘

💡 Troubleshooting

"ESP32 no se conecta": Verifica que PC y ESP32 estén en la MISMA red WiFi. Usa ipconfig (Windows) para obtener tu IP local.
"El cerebro_local.py es lento": Sin GPU, YOLO es ~5-10 FPS. Reduce resolución o skip frames.
Firewall: Windows Defender puede bloquear el puerto 8080. Añade excepción en "Configuración de firewall → Excepciones → Puertos".
