Paso 1: Configurar credenciales WiFi

  1. Copia shared/secrets.h.example a cada directorio de ESP32:
cp shared/secrets.h.example devices/esp32_cam/secrets.h
cp shared/secrets.h.example devices/esp32_wroom/secrets.h
  1. Abre cada secrets.h y reemplaza:
#define WIFI_SSID       "TU_RED_WIFI"
#define WIFI_PASSWORD   "TU_PASSWORD"
Nunca subas secrets.h a GitHub. El .gitignore lo excluye automáticamente.

Paso 2: Configurar URL de Vercel

Edita shared/config.h y cambia WS_HOST al hostname de tu despliegue Vercel:

#define WS_HOST  "fidae-rebirth.vercel.app"

Paso 3: Deploy del servidor en Vercel

  1. Instala Vercel CLI: npm install -g vercel
  2. Login: vercel login
  3. En la raíz del proyecto: vercel --prod
Vercel detecta api/socket.js como función Node.js automáticamente. El dashboard web/index.html se sirve como estático en /.

Paso 4: Flash de firmware

ESP32-CAM (ojo)

  1. Arduino IDE → Board: "ESP32 Wrover Module", Flash Size: 4MB (FS: 1MB, OPI: off)
  2. Instalar librerías: ArduinoJson, arduinoWebSockets
  3. Abrir devices/esp32_cam/ojo_esp32_cam.cpp
  4. Seleccionar puerto y subir

ESP32-WROOM (traductor)

  1. Arduino IDE → Board: "ESP32 Dev Module"
  2. Abrir devices/esp32_wroom/traductor_esp32_wroom.cpp
  3. Subir (con secrets.h creado en Paso 1)

Arduino Uno (músculo)

  1. Arduino IDE → Board: "Arduino Uno"
  2. Abrir devices/arduino_musculo/m_sculo_arduino_uno.cpp
  3. Conectar servos: Pan→pin 9, Tilt→pin 10
  4. Conectar I2C: SDA→A4, SCL→A5, con pull-ups 4.7kΩ a 3.3V/5V

Paso 5: Ejecutar Colab (cerebro)

  1. Abrir colab/cerebro_colab.py en Google Colab (Runtime → GPU T4)
  2. Colab descarga yolov8n.pt automáticamente (~6MB)
  3. El notebook se conecta al WebSocket de Vercel y comienza a tracktear

Solución de problemas

ProblemaSolución
ESP32 no conecta WiFiVerifica secrets.h — SSID y password correctos
WebSocket no se conectaVerifica WS_HOST en config.h — debe ser tu proyecto Vercel
Servos no se muevenCheca I2C: SDA→A4, SCL→A5; pull-ups 4.7kΩ; Slave addr 0x08
Colab se cuelgaAsegúrate de usar Runtime → T4 GPU; reinicia el runtime
Video se caeESP32-CAM tiene reconexión automática cada 5s; revisa logs Serial (115200 baudios)
