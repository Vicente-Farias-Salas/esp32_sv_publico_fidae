☁️ Vercel Setup — WebSocket Relay

api/socket.js actúa como relay WebSocket entre ESP32-CAM, Colab y ESP32-WROOM. Identifica clientes via query param ?type=.

📋 Requisitos

CuentaVercel (gratis)
Node.js≥18 (Vercel la gestiona en deploy)
GitPara push al repo conectado

🚀 Deploy

# Opción 1: GitHub (push triggers deploy automático)
git add -A
git commit -m "deploy"
git push origin main

# Opción 2: Vercel CLI
npm install -g vercel
vercel login
vercel --prod

📡 Endpoints

wss://TU-PROJECTO.vercel.app/api/socket?type=camera      ← ESP32-CAM
wss://TU-PROJECTO.vercel.app/api/socket?type=translator   ← ESP32-WROOM
wss://TU-PROJECTO.vercel.app/api/socket?type=colab        ← Colab
wss://TU-PROJECTO.vercel.app/api/socket?type=viewer       ← Dashboard

🔄 Ruteo de datos

camera (binary)  →  relay  →  colab (binary)
colab (text JSON)  →  relay  →  translator (text) + viewer (text)
colab (binary)     →  relay  →  viewer (binary, video procesado)

⚙️ Routing (vercel.json)

{
  "version": 2,
  "routes": [
    { "src": "/api/socket",   "dest": "/api/socket.js" },
    { "src": "/$",            "dest": "/web/index.html" },
    { "src": "/(.*)",         "dest": "/web/$1" }
  ]
}

💡 Troubleshooting

WebSocket no conecta: Verifica que WS_HOST en config.h coincida con tu proyecto Vercel.
Cold starts: Vercel puede tardar ~2s en iniciar la función. El primer connect lleva un poco más.
