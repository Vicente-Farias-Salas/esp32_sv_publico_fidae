📡 ESP32-WROOM Setup (Traductor)

Recibe coordenadas JSON (pan/tilt) por WebSocket y las envía por I2C al Arduino.

📋 Requisitos

HardwareESP32-WROOM-32 (DevKit o placa suelta)
I2CSDA → GPIO21, SCL → GPIO22
LibArduinoJson v6, arduinoWebSockets

⚙️ Configuración Arduino IDE

Tools → Board: "ESP32 Dev Module"
       → Flash Size: "4MB"
       → Core: "esp32"  # viene con el board package

🔗 I2C (conexión al Arduino)

ESP32-WROOMArduino UnoNota
GPIO21 (SDA)A4Con pull-up 4.7kΩ a 3.3V/5V
GPIO22 (SCL)A5Con pull-up 4.7kΩ a 3.3V/5V
GNDGNDComún obligatorio

🔐 Credenciales y flash

cp shared/secrets.h.example devices/esp32_wroom/secrets.h
# Editar con SSID y password de tu WiFi

# Flash:
esptool.py --port COMx --baud 460800 write_flash -z 0x1000 firmware.bin
# O vía Arduino IDE (más simple)

🔌 Cómo funciona

Cada vez que el Colab detecta un objeto:

  1. Envía JSON: {"pan":90, "tilt":120} por WebSocket
  2. El relay (Vercel) lo reenvía a ?type=translator
  3. ESP32-WROOM lo deserializa y clampa a [0,180]
  4. Lo envía como 2 bytes por I2C (Slave addr 0x08)

💡 Troubleshooting

I2C error (status!=0): Verifica pull-ups 4.7kΩ y GND común. El protocolo es 3.3V, usa level-shifter si Arduino es 5V.
Monitor Serie: 115200 baudios. Busca "WiFi OK", "Translator WS listo", "I2C X:YY Y:ZZ OK"
