🧠 Google Colab Setup

El "cerebro" del sistema. Ejecuta YOLOv8n con GPU para detectar objetos, calcular ángulos de servo y enviar coordenadas por WebSocket.

📋 Requisitos

RecursoGoogle Colab (gratis con GPU T4)
ModeloYOLOv8n (~6MB, se descarga automáticamente)
GPURuntime → Change runtime type → T4

🔧 Configuración

Runtime GPU

Runtime → Change runtime type
→ Hardware accelerator: GPU T4
→ Runtime: Automatic

URL del WebSocket

Edita la primera línea de configuración en ambos archivos:

# colab/cerebro_colab.py
WS_URL = "wss://TU-PROJECTO.vercel.app/api/socket?type=colab"

# colab/sistema_de_vision_fidae.py
WS_URL = "wss://TU-PROJECTO.vercel.app/api/socket?type=colab"

🔍 Qué hace el Cerebro

  1. Recibe frame JPEG (320×240) del ESP32-CAM vía WebSocket
  2. Corre YOLOv8n → detecta personas/objetos
  3. Calcula error: centro_obj - (160, 120)
  4. Aplica pursuit smoothing: coord -= error / SUAVIDAD
  5. Envía JSON {"pan":X, "tilt":Y} → ESP32-WROOM
  6. Reenvía frame procesado (con HUD) → Dashboard web

💡 Troubleshooting

"YOLO no descarga": Conexión WiFi. En Colab, usa Runtime → Disconnect and delete.
"Sin GPU": El código detecta automáticamente. Si no hay GPU, usa CPU (más lento pero funciona).
Center bug: El centro es (160, 120) para QVGA. El código original tenía (320, 240) (bug crítico corregido).
